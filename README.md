# Houston LEAD

Modern marketing website for [Houston LEAD](https://houstonlead.com) — Greater Houston's premier business networking community.

Built with the same polished stack as SoftwareDesign.io: React, Vite, Tailwind CSS, Framer Motion, and Lenis smooth scrolling.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- **Home** — Hero, benefits, chapters preview, stats, testimonials, FAQ
- **Chapters** — Filterable directory of 22+ LEAD chapters
- **Membership** — Benefits and tier pricing
- **Find a Professional** — Member directory (placeholder for full roster integration)
- **Events** — Event types and calendar placeholder
- **Sponsorships** — Partner packages and audience reach
- **Apply** — Membership application form
- **About** / **Contact** / **Privacy** / **Terms**

No member portal — public marketing site only.
